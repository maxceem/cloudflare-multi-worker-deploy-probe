Scope and limitations:
- These are live echo-WebSocket tests, not a production gateway rollout or a
  load/stability test. No provider sessions, quotas, vault, or D1 were tested.
- Clearing WRANGLER_CI_OVERRIDE_NAME and WRANGLER_CI_MATCH_TAG only for companion
  subprocesses is necessary with this Wrangler version. It is a small adapter
  around implementation-specific CI behavior; retest on Wrangler upgrades.
- Test sockets connect directly to the immutable release Worker. There is no
  long-lived WebSocket proxy through the primary Worker.
- Runtime restart, network failure, recovery, release locking, artifact
  integrity, admission/auth, storage compatibility, and old-release cleanup
  still require a production design. No zero-disconnection guarantee is made.
- The deployment and old realtime release are retained for inspection. The
  generated build token is named multi-worker-button-probe-builds. Remove the
  test Workers and revoke that token when the demonstration is no longer needed.
